## 🔍 Quick Reference

### Commands
```bash
npm install          # Install dependencies
npm start           # Start development server
npm run build       # Build for production
npm test            # Run tests
```

### Key Files to Edit
- **Colors**: All `.css` files (search `#ff6b6b`)
- **Restaurant Name**: `Navbar.js`, `HeroSection.js`, `Footer.js`

- **Images**: `pages/Menu.js`, `pages/Gallery.js`
- **Contact Info**: `components/Footer.js`, `pages/Contact.js`
