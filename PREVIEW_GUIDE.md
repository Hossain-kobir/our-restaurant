## 🎨 Design Elements

### Color Scheme
```
Primary:   #ff6b6b (Coral Red)
Secondary: #ee5a6f (Pink)
Dark:      #2c3e50 (Navy)
Gray:      #7f8c8d (Gray)
Light:     #f8f9fa (Off-white)
```

### Typography
```
Headings:  Bold, 2.5rem - 4rem
Body:      Regular, 1rem - 1.1rem
Buttons:   Semi-bold, 1rem - 1.2rem
```

### Spacing
```
Sections:  5rem padding (top/bottom)
Cards:     1.5rem - 2.5rem padding
Gaps:      1rem - 2rem between elements
```

## 🌈 Visual Hierarchy

```
1. Hero Section (Largest, most prominent)

   ↓
```

## 💡 Design Tips

1. **Consistency** - Same spacing, colors, fonts throughout
2. **Hierarchy** - Clear visual importance levels
3. **Whitespace** - Breathing room between elements
4. **Contrast** - Dark text on light, light text on dark
5. **Alignment** - Everything lines up properly
6. **Balance** - Equal visual weight distribution
7. **Focus** - Clear call-to-action buttons
