# Quick Start Guide

## Getting Started in 3 Steps

### 1. Install Dependencies
```bash
cd our-restaurant
npm install
```

### 2. Start Development Server
```bash
npm start
```

The app will automatically open at `http://localhost:3000`

### 3. Build for Production
```bash
npm run build
```

## What You'll See

- **Home Page** - Beautiful hero section with featured dishes
- **Menu Page** - 8 delicious menu items with descriptions
- **Gallery Page** - 12 stunning food images
- **About Page** - Restaurant story and values
- **Contact Page** - Contact form and restaurant info

## Deployment

### Netlify (Easiest)
1. Run `npm run build`
2. Drag the `build` folder to netlify.com/drop
3. Done!

### Vercel
1. Push to GitHub
2. Import project on vercel.com
3. Deploy automatically

## Customization Tips

- **Colors**: Edit gradient colors in CSS files (search for `#ff6b6b`)
- **Images**: Replace Unsplash URLs with your own
- **Content**: Update text in page components
- **Menu Items**: Modify the `menuItems` array in `Menu.js`

## Need Help?

All components are well-organized in:
- `src/components/` - Reusable components
- `src/pages/` - Page components
- Each component has its own CSS file
